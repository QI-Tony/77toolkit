# Format Remove

A static 77 Toolkit-style web page for removing copied text formatting.

Paste content copied from ChatGPT, Gemini, docs, or web pages into the box. The
page removes common Markdown and rich-text artifacts while keeping paragraph
breaks readable, then lets the user copy the cleaned result.

## Files

- `index.html`
- `styles.css`
- `script.js`

No build step is required.
