# 77 Toolkit Home

77 Toolkit Home is the navigation page for `77toolkit.com`. It collects small,
focused browser tools and presents them as a quiet utility workspace.

## Visual Style

- Light gray page background with white tool cards.
- Restrained teal accent (`#126b63`) for primary actions, status, and small emphasis text.
- Compact, work-focused layout with sticky top navigation and a maximum content width near 1120px.
- Cards use subtle borders, soft shadows, and 8px radius.
- Typography is system sans-serif, with large first-screen headline text and smaller dense labels inside tool cards.
- Tool metadata is scannable: category pill, live/coming-soon status, short description, tags, and one clear action.
- The overall tone is lightweight, calm, practical, and browser-native rather than decorative or marketing-heavy.

## Published content

- 29 tools under `https://77toolkit.com/tools/<tool>/`
- Developer, Text, Image, and Web category pages
- Twelve practical guides under `https://77toolkit.com/guides/`
- About, Editorial Policy, Accessibility, Privacy, Terms, Contact, and Site Map pages
