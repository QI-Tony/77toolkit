How the collection is maintained

Useful output needs a reviewable method

Every published tool combines working browser functionality with task-specific guidance and explicit limitations.

Local by design

Text and selected files are processed with browser APIs. Tools do not fetch pasted URLs or send input to a 77 Toolkit backend.

Specific, not generic

Each page explains its own workflow, assumptions, failure cases, and better alternatives instead of repeating one template description.

Built for verification

Input stays visible, results can be reviewed before copying, and the production build checks metadata, links, page depth, and crawlability.
